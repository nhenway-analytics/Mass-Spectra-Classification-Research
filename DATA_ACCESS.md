# Data availability and sharing restrictions

The research used **1,500 electron-ionization mass-spectrum CSV files**, organized under four directories (`CM1`, `CM2`, `CM3`, `Isomers`) with **10 replicate spectra for each of 150 compounds**.

The **dataset's original creator, provenance, licensing and permission to redistribute have not been established from the provided materials**. For that reason, this GitHub draft does not include the raw spectra or source publication PDFs.

To reproduce locally, place authorized CSV files into the four named folders alongside `main.py`, install `requirements.txt`, then execute `python main.py`. Consult the data owner and applicable institutional policies before redistributing input files, publishing a derived dataset or adding a downloadable notebook containing raw samples.

The figures and aggregate metrics included here are derived outputs of the collaborative academic project. Nhen Way has confirmed that co-author Fatema Naoshin is comfortable with GitHub publication of the project. Permissions for any third-party input data must be handled separately.
