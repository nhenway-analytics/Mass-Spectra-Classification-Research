# Research Results

This folder contains summary results from the MSc Mass Spectra Classification research project.

- summary_by_seed.csv: Classification performance across 20 randomized evaluation runs.
- summary_stats.csv: Aggregated performance statistics for the three classification methods.

Methods compared:
- Cosine similarity
- Standard Min-Max statistic
- Robust Min-Max statistic

Note: Classification thresholds were optimized and evaluated on the same sampled comparisons. The reported performance is not independent out-of-sample validation.
